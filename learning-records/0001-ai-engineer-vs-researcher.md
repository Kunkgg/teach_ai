# 0001 — AI Engineer 和 AI Researcher 是两条不同的路

## Date
2026-08-03

## Context
用户是一名 37 岁的 Python 全栈工程师，想转型 AI 工程方向。找到的学习资源（如 rohitg00/ai-engineering-from-scratch 的 500+ 课时）覆盖了从数学基础到模型训练的完整路径，但用户认为"太慢了"。

## Insight
**AI Engineer 和 AI Researcher 是两条完全不同的路径。** 对于一个已有 Python 后端经验、目标是构建 AI 应用（而非训练模型）的工程师来说：

1. 数学基础（线性代数、概率论推导）**不是必需的** — 理解概念即可
2. 模型训练、GPU 优化 **不是必需的** — 使用 API 即可
3. 核心技能栈是：**LLM API → RAG → LangChain/LCEL → LangGraph/Agent → 生产化**
4. rohitg00 路线图中 Phase 00-07 大部分可跳过，聚焦 Phase 08-16

## Implications
- 学习路径可以从 320 小时压缩到 ~60 小时
- 每个知识点都应直接服务于"可信看板 + AI"的最终项目
- "项目经验 > 学历" 意味着用户的项目 demo 是面试的核心竞争力

## Status
Active — 这个认知框架指导整个学习计划的设计。
